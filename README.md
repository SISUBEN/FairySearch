Fairy Search Engine
--------------
FairySearch 是一个免费的视频搜索引擎，它通过分析用户的浏览数据和喜欢推荐视频。

## How to use / 如何使用
> ⚠️使用本程序前请确保本地环境是完整版Python 3.8+
### 从源码构建
1. 首先使用git克隆本项目
`$ git clone https://github.com/SISUBEN/FairySearch.git`  
2.切换目录`cd ./FairySearch-main/`
